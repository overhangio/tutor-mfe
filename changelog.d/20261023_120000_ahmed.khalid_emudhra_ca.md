- [Security] Upgrade Node.js to v24.22.1 in the MFE images, while keeping npm at 11.6.1 because later versions reject the lockfiles of some Ulmo MFEs, so that they no longer trust the compromised eMudhra/emSign CA certificates (https://emudhra.we-have-a-problem.com/). Pull the new image with `tutor images pull mfe`, or rebuild it with `tutor images build mfe` if you build your own. (by @ahmed-arb)
